# Stackd

A premium web development agency site for **Stackd**. Built to showcase polished agency branding, responsive layout craft, and conversion-focused presentation.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- Manrope + JetBrains Mono (Google Fonts)

## Sections

1. Fixed navbar with mobile menu
2. Hero with highlights bar and agency positioning
3. Technology marquee strip
4. Services grid
5. Process section
6. Projects section
7. Why Stackd section
8. Final CTA with contact form
9. Footer with credits

## Run locally

```bash
npm install
npm run dev
npm run build
npm run preview
```
